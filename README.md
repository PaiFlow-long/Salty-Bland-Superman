# 咸淡超人 🍎

> 今日你是「咸人」，还是「淡人」？

一个 **1 分钟测「今日状态」** 的网页小工具。答 5 道核心题（视情况再加问 1–3 道补充题），结合当天日期，得到一张**今日状态卡**：七维状态 → 咸度 × 情绪正负 → 12 种主类型，附上 **今日宜忌、幸运物、彩蛋**，还能一键生成分享卡。

- 纯静态：原生 HTML / CSS / JS，**无框架、无构建、无后端**
- 零服务器成本：所有计算都在浏览器里完成
- 隐私优先：不收集任何数据，不上传、不留痕
- 随机可控：同一天、同一答案 → 同一个结果（可复现、可分享）

## 怎么玩

1. 打开页面，点「开始测评 →」。
2. 回答 5 道核心题：睡眠、工作/学习安排、社交、身体情绪、今天想怎么过。
3. 部分答案会触发 1–3 道**条件追问**（例如「几乎没睡」后会追问「现在更接近困还是炸」）。
4. 提交后得到「今日状态卡」：咸度条、情绪正负、一句话诊断、日期语境评价、今日宜忌、幸运物、彩蛋。
5. 点「生成分享卡」生成一张竖版图片，可保存 / 分享。

## 打分体系（核心）

### 1. 七维状态向量

每个选项会往这 7 个维度上加 / 减分，最终 clamp 到各自范围内。

| 维度 | 含义 | 范围 |
|---|---|---|
| **E** 能量 | 身体电量 | 0 – 100 |
| **W** 意愿 | 想不想动 | 0 – 100 |
| **L** 负荷 | 今天被塞了多少事 | 0 – 100 |
| **S** 社交 | 社交电量 | 0 – 100 |
| **M** 情绪 | 情绪好坏（0 为中性）| −100 – 100 |
| **C** 掌控 | 觉得今天能不能自己说了算 | 0 – 100 |
| **R** 躁度 | 烦躁、易怒、一点就炸 | 0 – 100 |

基线（七维初始值）：`E/W/L/S/C/R = 50`，`M = 0`。也就是说，什么都不加时你处在「中性 / 温吞」的位置，淡和咸都是往两侧的偏离。

### 2. 咸度（唤醒 / 激活轴）

咸度衡量的是**唤醒强度**——越高越想动、越坐不住。

```
答题咸度 A = 0.18·E + 0.10·W + 0.28·L + 0.24·R + 0.11·S + 0.05·C + 0.04·M
最终咸度  = clamp( 0.7·A + 0.3·日期先验 + max(0, R − 80),  0, 100 )
```

- **L（负荷）、R（躁度）权重最高**：事情越多、越躁，人就越「咸」。
- **最后的 `max(0, R − 80)` 是「炸放大器」**：当躁度超过 80，额外推高咸度，让「炸毛」和普通「燥咸」拉开差距。
- **最终咸度 = 70% 你的答案 + 30% 日期先验**：同样的答案，节前会明显更咸、节后会明显更淡。

> 语义说明：**咸 ≠ 坏**。咸只代表「高唤醒」，既可能是正向的**清咸**（睡饱了、有劲想干），也可能是负向的**燥咸 / 炸咸**（没睡好、烦躁、一点就炸）。是正还是负，由下面的「情绪正负」决定。

### 3. 情绪正负（效价轴）

情绪正负衡量的是**方向**——正 = 好，负 = 差。

```
情绪正负 V = 0.50·M + 0.15·C + 0.10·S − 0.30·R − 0.10·L      （clamp 到 −100 ~ 100）
```

- **M（情绪）主导**；**R（躁度）、L（负荷）拉向负向**。
- 展示分档：`V < −30` → 负向 😣；`−30 ≤ V ≤ 30` → 中性 😐；`V > 30` → 正向 😊。

### 4. 主类型判定（12 种 + 矛盾咸）

先看是否构成**矛盾咸**（高能量却完全失控，罕见）：

```
if (E ≥ 70 && C ≤ 30)  →  矛盾咸·内爆型
```

否则用「咸度 × 情绪正负」两轴定位：

```
咸度档 sb： salt < 49 → 0（淡）| < 58 → 1（偏淡）| < 67 → 2（中）| 其余 → 3（咸）
情绪档 vb： val < −30 → 0（负）| ≤ 30 → 1（中）| 其余 → 2（正）
主类型键  =  b{sb}v{vb}
```

12 种主类型：

| 键 | 类型名 | 键 | 类型名 |
|---|---|---|---|
| b0v0 | 低电量乌云 ☁️ | b2v0 | 燥咸火药桶 🧨 |
| b0v1 | 断电棉花糖 🍡 | b2v1 | 咸鱼翻身组 🐟 |
| b0v2 | 躺平小天使 😌 | b2v2 | 清咸元气弹 ⚡ |
| b1v0 | 佛系摆烂猫 🐱 | b3v0 | 炸毛火山口 🌋 |
| b1v1 | 半糖温吞水 💧 | b3v1 | 高压咸鱼王 👑 |
| b1v2 | 微醺奶油泡 🫧 | b3v2 | 超级咸战神 🔥 |
| — | — | maodun | 矛盾咸·内爆型 🌀 |

### 5. 日期先验

日期会给你一个「先验咸度」，再与你的答案按 7:3 融合。

**周几先验**（0 = 周日）：

| 周日 | 周一 | 周二 | 周三 | 周四 | 周五 | 周六 |
|---|---|---|---|---|---|---|
| 50 | 38 | 44 | 50 | 56 | 62 | 68 |

规律：节后第一天最淡，周一第二淡；周一到周五逐步变咸；周六周内最咸；周日回落到约周三的水平。

**特殊日期先验**（内置于 `SPECIAL`，按年存储）：

| 场景 | 先验咸度 |
|---|---|
| 节前最后一天 | 74（最咸）|
| 假期当天 | 44 |
| 假期最后一天 | 46 |
| 调休补班日 | 38 |
| 节后第一个工作日 | 30（最淡）|

> 目前已内置 **2026（官方口径）** 与 **2027（按现行放假办法推算）** 的中国法定节假日。2027 的调休补班日待官方通知发布后补入。

**日期语境文案**：当命中节假日语境、或是**周一 / 周五 / 周六 / 周日**时，状态卡会多一句带日期的评价（例如「今天是国庆最后一天，测出断电棉花糖太合理了……」）。普通周二 / 三 / 四不触发。

### 6. 条件追问

核心 5 题之后，按答案触发追问，优先级为 **睡眠 → 情绪 → 意愿 → 工作 → 社交**，最多取前 3 道。例如：

- 睡眠选「翻来覆去 / 几乎没睡」→ 追问「现在更接近困、炸，还是又困又炸？」（决定往「淡」还是「燥咸」走）
- 今天想「彻底躺」→ 追问「主动躺 / 被动躺 / 逃避躺？」

追问的答案同样会加减七维，从而影响最终类型。

### 7. 受控随机（可复现）

宜忌之外的随机内容（诊断句、幸运物、彩蛋）都使用**种子随机**：

```js
seed = hashCode(日期 + JSON.stringify(答案))   // FNV-1a 变体
rand = lcg(seed)                                // 线性同余
```

因此：**同一天 + 同一答案 = 同一结果**（可复现、可对照、可分享）；换一天或换答案，结果就变。

## 今日宜忌 · 幸运物 · 彩蛋

- **今日宜 / 今日忌**：按主类型给出两条「宜」和两条「忌」。
- **幸运物**：从 40 个物件池里受控随机抽一个（颈枕、黑咖啡、雨伞……）。
- **彩蛋**：从 20 条「今日小惊喜」里受控随机抽一条（「今天适合听一首老歌。」……）。

三者各玩各的，都**不参与打分**，只负责让结果「有点意思」。

## 分享卡

点「生成分享卡」，用 **Canvas** 现场画出一张 `1080 × 1560` 的竖版卡片（朋友圈 / 故事尺寸友好），包含：

品牌徽标 → 标题与日期 → 类型 emoji 与名称 → 咸度条 → 情绪正负 → 日期语境评价（若有）→ 今日宜 / 今日忌 → 幸运物 → 彩蛋 → 页脚 + 右下角二维码。

可直接「保存图片」（导出 PNG）。全程本地生成，不上传服务器。

卡片右下角有一个指向本站的二维码（`assets/qrcode.png`），扫码即可打开 https://salty-bland-superman.pages.dev。

> **换域名时**：二维码是静态图片，改域名后需重新生成，命令见下方「重新生成二维码」。

## 重新生成站点图标

`assets/` 下的图标都由 `assets/logo.png` 派生。若换了 logo，重跑一遍即可：

```bash
python - <<'PY'
from PIL import Image
im = Image.open('assets/logo.png').convert('RGBA')
im.resize((32,32), Image.LANCZOS).save('assets/favicon.ico',
    sizes=[(16,16),(32,32),(48,48)], bitmap_format='png')
for s in (180,192,512):
    im.resize((s,s), Image.LANCZOS).save(f'assets/icon-{s}.png')
PY
```

## 部署到 Cloudflare Pages

这是一个**纯静态**项目，任何静态托管都能部署。推荐 Cloudflare Pages（免费、全球 CDN、国内访问相对友好）。

**方式 A：网页拖拽（最快，无需 git）**

1. 登录 Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
2. 把整个项目文件夹（`index.html` + `assets/`）拖进去。
3. 部署完成，得到形如 `https://<项目名>.pages.dev` 的地址。

**方式 B：连接 GitHub 仓库（可自动更新，推荐）**

1. 新建一个 GitHub 仓库，把本项目提交上去。
2. Cloudflare Pages → **Connect to Git** → 选择该仓库 → 框架预设 `None`、**构建命令留空**、输出目录填 `/`（纯静态，无需构建）。
3. 之后每次 push 会自动重新部署。

> 详细的逐步操作见 **[DEPLOY.md](./DEPLOY.md)**。

> 本项目是独立项目，使用单独仓库 `Salty-Bland Superman`，不与个人主站仓库混在一起。

## 设计原则

| 原则 | 说明 |
|---|---|
| 答题轻 | 核心 5 题，追问最多 3 道 |
| 计算重 | 七维向量 + 日期先验 + 追问分支 |
| 文案稳 | 静态文案池 + 受控随机，结果可复现 |
| 随机可控 | 哈希种子，同天同答结果一致 |
| 零后端 | 无账号、无数据库、无服务器 |
| 单文件 | 一个 index.html 装下全部逻辑 |
| 隐私优先 | 不收集数据，全部本地计算 |
